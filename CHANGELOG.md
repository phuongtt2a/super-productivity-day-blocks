# Release notes

## 0.1.0 — First preview

Welcome to **Day Blocks**! Plan today's tasks and habits in a continuous, four-part timeline.

- Four blocks: Morning, Afternoon, Evening, and Night, in a single horizontal row.
- Drag or use Plan to move tasks and habits out of Unassigned.
- Arrange session order and choose exact times or flexible durations.
- Continue one task or habit across multiple blocks, without duplicating it.
- Reuse preferred times for habits on future scheduled days.
- Update original tasks and habit progress, while keeping planned time separate from completed time.
- Mobile-friendly sideways scrolling, keyboard-accessible actions, and an appearance that respects Super Productivity's fonts and wallpaper.

This is a **preview for user testing**, not an accepted stable release.
